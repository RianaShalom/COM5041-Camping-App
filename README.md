Frontend - All you need to have is Live Server on VSCode, and you can give it a run from the index.html



# Steps to run:
- Install the extension "Live Server" by Ritwick Dey
- Right-click index.html → Open with Live Server
- When logging in, make sure to verify the email link sent to you. You can do this with either your email, or with `10minutemail.com`
